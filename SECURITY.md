# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for a security problem.

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/Grenish/xenon/security/advisories/new).
Include the affected version, steps to reproduce, and the impact you expect. We aim to acknowledge a
report within a few days and will keep you updated until it is fixed.

## Supported versions

XenonCMS is pre-release (0.x). Security fixes go to the latest published version only.
